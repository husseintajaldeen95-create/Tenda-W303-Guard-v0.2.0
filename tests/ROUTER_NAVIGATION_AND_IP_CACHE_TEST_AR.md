# اختبار إصلاح التنقل وربط IP — v0.2.8

## قبل الاختبار
- الهاتف متصل بشبكة Tenda W303R.
- تسجيل الدخول إلى واجهة الراوتر داخل التطبيق.
- لا تغيّر إعدادات Permit/Forbid أثناء هذا الاختبار؛ الإصدار يقرأ الصفحات فقط.

## اختبار اختصارات الصفحات
1. اضغط «قائمة أجهزة DHCP» وتحقق من ظهور جدول Host Name / IP Address / MAC Address / Lease Time.
2. اضغط «الأجهزة اللاسلكية المتصلة» وتحقق من ظهور جدول MAC Address / Bandwidth.
3. اضغط «السماح أو منع اتصال Wi-Fi» وتحقق من فتح Wireless > Access Control.
4. اضغط «تصفية المواقع وجدولة الوصول» وتحقق من فتح Security > URL Filtering على المسار `/firewall_urlfilter.asp`. تحقق من ظهور حقول Start IP وEnd IP وURL Character String والوقت وأيام الأسبوع.
5. اضغط «ضبط وقت الراوتر» وتحقق من فتح Tools > Time Settings على المسار `/system_hostname.asp`. لا تحفظ أي تغيير؛ أرسل تقرير فحص الحقول إذا ظهرت الصفحة.
6. اضغط «QoS وتحديد السرعة» وتحقق من فتح Bandwidth Control.
7. اضغط «QoS - Traffic Statistics» وتحقق من ظهور جدول IP Address وUplink/Downlink Rate وSent/Received Bytes.

## اختبار دمج DHCP وWi-Fi
1. اضغط «تحديث القائمتين تلقائياً».
2. تحقق من أن الأجهزة التي تظهر في القائمتين تُدمج حسب MAC.
3. إذا ظهر MAC في Wireless ولم يظهر في لقطة DHCP الحالية، يجب أن يعرض التطبيق آخر IP معروف فقط إذا كان قد سجله خلال آخر 24 ساعة، مع عبارة «آخر IP معروف».
4. لا تعتبر العنوان التاريخي عنواناً حاضراً مؤكداً؛ أعد قراءة DHCP للتحقق منه.

## اختبار Traffic Statistics
1. افتح QoS > Traffic Statistics.
2. ابدأ المراقبة الحية.
3. نفّذ تنزيل/رفع من جهاز معروف لمدة دقيقة.
4. تحقق من تغير Uplink/Downlink لذلك الـ IP.
5. إذا كان MAC من سجل DHCP تاريخياً، يجب أن تظهر عبارة «آخر سجل DHCP معروف» بجانبه.

## نتيجة الاختبار المطلوب إرسالها
- صورة لكل صفحة فشل اختصارها.
- تقرير «فحص حقول الصفحة الحالية» إذا لم تُفتح الصفحة المطلوبة.
- صورة لوحة المشتركين بعد «تحديث القائمتين تلقائياً».
- لا ترسل كلمة مرور الراوتر أو بيانات الدخول.
