# اختبار Static Assignment — الإصدار 0.2.11

## قبل الاختبار

- اتصل بشبكة Tenda W303R وافتح التطبيق وسجّل الدخول إلى الراوتر.
- تأكد أن عنوان الراوتر في التطبيق صحيح، مثل `192.168.0.1`.
- لا تغيّر إعدادات DHCP أو MAC Filtering أثناء الاختبار.

## 1. قراءة الحجوزات

1. اضغط «قراءة حجوزات IP من الراوتر».
2. يجب أن يفتح التطبيق `Advanced > LAN Settings > DHCP Client List`.
3. يجب أن يعرض عدد سجلات DHCP وعدد حجوزات Static Assignment كلٌّ على حدة.
4. إذا كان جدول Static Assignment فارغاً، يجب أن تظهر رسالة «لا توجد حجوزات IP ثابتة حالياً»، ولا يجوز اعتبار سجلات DHCP حجوزات ثابتة.

## 2. فحوص منع التعارض

| حالة الاختبار | النتيجة المتوقعة |
|---|---|
| IP مستخدم في DHCP بواسطة MAC مختلف | رفض الحجز وذكر MAC الذي يستخدم IP |
| IP محجوز في Static Assignment لـ MAC مختلف | رفض الحجز |
| MAC لديه حجز ثابت آخر بعنوان IP مختلف | رفض الحجز وطلب حذف الحجز القديم يدوياً أولاً |
| نفس IP ونفس MAC موجودان بالفعل | إظهار «الحجز موجود بالفعل» وعدم تعبئة نموذج جديد |
| IP يساوي عنوان الراوتر | رفض الحجز |
| IP خارج شبكة الراوتر /24 | رفض الحجز |
| الجهاز نفسه يحمل IP عبر DHCP وMAC مطابق | السماح بالفحص إذا لم يوجد حجز ثابت متعارض |

## 3. اختبار تعبئة النموذج

1. أدخل آخر مقطع من IP، مثل `110`، أو أدخل العنوان كاملاً `192.168.0.110`.
2. أدخل MAC بالشكل `AA:BB:CC:DD:EE:FF`.
3. اضغط «فحص التعارض وتعبئة نموذج الراوتر» ثم وافق على الفحص.
4. عند عدم وجود تعارض، يجب أن يملأ التطبيق حقل IP بالأرقام الأخيرة فقط وحقول MAC الستة.
5. يجب ألا يضغط التطبيق `Add` أو `OK` تلقائياً.
6. راجع القيم في واجهة الراوتر. إذا كانت صحيحة، اضغط `Add` ثم `OK` يدوياً.
7. اضغط «قراءة حجوزات IP من الراوتر» مرة أخرى للتحقق من ظهور الحجز.

## 4. اختبار الحذف

- افتح `DHCP Client List`.
- في جدول Static Assignment، اضغط `Delete` بجانب الحجز المطلوب فقط.
- راجع الصفوف ثم اضغط `OK` في واجهة الراوتر.
- ارجع إلى التطبيق واضغط «قراءة حجوزات IP من الراوتر» للتأكد من اختفاء الحجز.

## حدود الاختبار

هذا الإصدار يقرأ الحجوزات ويقارنها بإيجارات DHCP، ويفحص التعارضات ويملأ حقول النموذج فقط. لا ينفذ حفظاً أو حذفاً آلياً على الراوتر. يجب اختبار قراءة الجدول وتعبئة الحقول على جهاز Tenda الفعلي قبل الاعتماد على الميزة.
