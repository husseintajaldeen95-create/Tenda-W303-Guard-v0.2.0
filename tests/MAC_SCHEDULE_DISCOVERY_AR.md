# استكشاف صفحة جدولة MAC — v0.2.14

## الهدف
تحديد صفحة `MAC Address Filter Settings` الحقيقية ونموذجها قبل بناء أي أتمتة تعدّل سياسات الأجهزة.

## ما أضيف
- اختصار مستقل يفتح `Security > MAC Address Filter Settings` من قائمة الراوتر بالاسم الظاهر.
- aliases لاسم الصفحة في بعض اختلافات التسمية.
- الفحص تلقائي عند فتح الصفحة، مع بقاء زر فحص حقول الصفحة الحالية متاحاً.

## ما لا يفعله هذا الإصدار
- لا يغيّر Filter Mode.
- لا يغيّر Access Policy أو MAC Address.
- لا يغيّر وقت البداية أو النهاية أو الأيام أو Enable.
- لا يضغط OK أو يرسل POST إلى الراوتر.
- لا يشغّل أي مؤقت أو مهمة خلفية.

## خطوات الاختبار
1. اتصل بـ Tenda W303R وسجّل الدخول.
2. اضغط «جدولة الإنترنت حسب MAC».
3. تأكد أن الصفحة المعروضة هي صفحة MAC Address Filter Settings ذات حقول Access Policy وPolicy Name وMAC Address وTime وDay(s) وEnable.
4. افتح «أدوات التشخيص»، واضغط «فحص حقول الصفحة الحالية».
5. اضغط «نسخ تقرير التشخيص» وأرسل النص الناتج.

## بيانات مطلوبة قبل كتابة الأتمتة
- عنوان الصفحة الحقيقي والمسار داخل الإطار.
- form action وmethod وonsubmit.
- أسماء ومعرّفات حقول Access Policy وPolicy Name وMAC Address.
- حقول وقت البداية والنهاية وقيم خيارات الساعات والدقائق.
- حقول الأيام وخيار Enable.
- وظيفة زر OK أو دالة JavaScript التي تحفظ السياسة.
- طريقة قراءة السياسات المحفوظة لكل الأجهزة، وعدد السياسات المدعوم.

بعد التحقق، تُبنى آلية مستقلة تحفظ القيم الأصلية لكل سياسة مفعّلة، وتصفّر وقت بداية كل جهاز عند حلول وقته هو، ثم تستعيد القيمة الأصلية عند 23:00 مع إبقاء نهاية السماح 23:55. لا تُطبّق على السياسات غير المفعّلة أو غير المجدولة.
