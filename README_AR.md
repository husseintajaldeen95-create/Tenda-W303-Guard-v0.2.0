# Tenda W303 Guard — v0.2.1 Device Discovery Fix

تطبيق Android بلغة Java لواجهة الإدارة المحلية لراوتر Tenda W303R V3.0، Firmware `V5.07.46_en`.

## تغييرات v0.2.1

- محاولة قراءة جدول DHCP أو Wireless تلقائياً بعد تحميل صفحة الراوتر المدعومة.
- إضافة زر تحديث صفحة الراوتر وزر الرجوع إلى الصفحة الرئيسية.
- تحسين البحث عن عناصر التنقل في الروابط والأزرار والعناصر التي تستخدم onclick أو title أو alt.
- إظهار أخطاء تحميل الصفحة وHTTP في شريط الحالة بدلاً من ترك المستخدم دون تفسير.
- إظهار وقت آخر قراءة DHCP وآخر قراءة Wi-Fi لتمييز اللقطات القديمة عن الحديثة.
- عرض كل جهاز في بطاقة منفصلة، مع إمكانية تعيين اسم محلي محفوظ على الهاتف ونسخ MAC.
- استعادة عنوان الراوتر الأخير من إعدادات التطبيق.
- إظهار نتيجة القراءة وعدد السجلات المكتشفة أو تنبيه المستخدم عند عدم التعرف على الجدول.

## الاستخدام

1. اتصل بشبكة Tenda من الهاتف.
2. افتح التطبيق واتصل بعنوان الراوتر المحلي، الافتراضي `192.168.0.1`.
3. سجّل الدخول داخل صفحة الراوتر المضمنة في التطبيق.
4. افتح `Advanced > DHCP Client List`. يحاول التطبيق قراءة الجدول تلقائياً بعد تحميل الصفحة. ويمكن الضغط على «قراءة الأجهزة من الصفحة الحالية».
5. افتح `Wireless > Wireless Connection Status` لتحديث لقطة أجهزة Wi-Fi.
6. تظهر الأجهزة في بطاقات. يمكن تغيير الاسم محلياً على الهاتف.

## حدود هذه النسخة

- هذه النسخة لا تزال تعتمد واجهة الراوتر داخل WebView؛ لذلك لا تمثل مراقبة خلفية لحظية.
- يجب أن تكون صفحة الراوتر مسجلة الدخول وأن تكون صفحة DHCP أو Wireless ظاهرة لكي يقرأ التطبيق الجدول.
- لقطة DHCP تعني أن الجهاز حصل على عنوان من DHCP، ولا تثبت وحدها أنه متصل الآن.
- لقطة Wireless Connection Status هي مؤشر الأجهزة اللاسلكية الظاهرة وقت القراءة.
- `20M` و`40M` في صفحة Wireless Connection Status تمثل عرض قناة Wi-Fi، وليست سرعة الإنترنت.
- أسماء الأجهزة المخصصة تُحفظ محلياً على الهاتف ولا تُكتب في الراوتر.
- لا ينفذ التطبيق الحظر أو تحديد السرعة أو تغيير إعدادات الراوتر في هذا الإصدار. يلزم فحص نماذج Security وQoS وحقولها الفعلية قبل تنفيذ أوامر كتابة آمنة.

## بناء APK عبر GitHub Actions

1. ارفع محتويات مجلد المشروع إلى جذر مستودع GitHub، بحيث يكون `settings.gradle` في جذر المستودع.
2. افتح Actions وشغّل `Build Tenda W303 Guard APK` أو ادفع commit جديداً إلى `main` أو `master`.
3. نزّل `TendaW303Guard-debug-apk` من Artifacts.

بيئة البناء: JDK 17، Gradle 8.7، Android Gradle Plugin 8.6.1، Android SDK 35.

## اختبار التوافق

تمت مراجعة الشيفرة وتحديثها في هذه النسخة، لكن يجب بناء APK في GitHub Actions واختبار الاتصال وقراءة الجدولين على الراوتر الحقيقي. لا تعتبر النسخة مؤكدة التوافق قبل إرسال نتيجة Actions وتقرير قراءة DHCP وWireless من الهاتف.


## الإصدار 0.2.2 – Iframe table reader

- يتعامل مع صفحة DHCP Client List داخل الإطار `/lan_dhcp_clients.asp` عندما تكون الصفحة الأم `/advance.asp`.
- يربط كل جدول بمسار الإطار الذي يحتويه في تقرير التشخيص.
- يحدد أعمدة DHCP وWi-Fi من عناوين الأعمدة بدلاً من افتراض ترتيب ثابت.
- يعيد محاولة القراءة خمس مرات بفاصل 650 ms إذا لم يكن إطار الصفحة قد اكتمل تحميله.
- يضيف معاينة محدودة لصفوف جداول الأجهزة في تقرير التشخيص؛ لا يغيّر إعدادات الراوتر ولا يرسل أوامر حظر أو تحديد سرعة.

**حدود التحقق:** تم فحص مصدر المشروع وتعديل منطق القراءة. لم يُبنَ APK في هذه البيئة لعدم توفر Android SDK/Gradle، ولم يُختبر الاتصال الحي بالراوتر. يجب بناء النسخة عبر GitHub Actions ثم اختبارها على الراوتر الفعلي.
