# Tenda W303 Guard — v0.2.0 Device Discovery

تطبيق Android بلغة Java لإدارة راوتر Tenda W303R V3.0 ذي Firmware `V5.07.46_en`.

## ما أُضيف في هذه النسخة

- تمييز جدول `DHCP Client List` من خلال أعمدته: Host Name وIP Address وMAC Address وLease Time.
- تمييز جدول `Wireless Connection Status` من خلال أعمدته: MAC Address وBandwidth.
- قراءة عنوان MAC من كل جدول وتوحيده إلى صيغة `AA:BB:CC:DD:EE:FF`.
- دمج لقطة DHCP مع لقطة Wi-Fi باستخدام MAC Address.
- عرض اسم الجهاز وIP ومدة DHCP Lease عند توفرها.
- عرض حالة ظهور الجهاز في لقطة Wi-Fi وعرض قناة Wi-Fi عند توفره.
- الاحتفاظ بلقطتي DHCP وWi-Fi في الذاكرة أثناء جلسة التطبيق، مع استبدال كل لقطة عند إعادة قراءتها.
- عدم اعتبار الجداول غير المعروفة بيانات DHCP أو دليلاً على الاتصال.

## حدود مهمة

- `20M` و`40M` في صفحة Wireless Connection Status تعني عرض قناة Wi-Fi، وليست سرعة تنزيل الإنترنت أو رفعه.
- ظهور MAC في صفحة Wireless Connection Status مؤشر على وجوده في لقطة الأجهزة اللاسلكية عند تحديث الصفحة. يجب الضغط على Refresh في صفحة الراوتر قبل إعادة القراءة.
- DHCP Client List تعرض سجلات حصلت على عناوين من DHCP؛ وجود السجل لا يثبت وحده أن الجهاز متصل الآن.
- لا تنفذ هذه النسخة حظراً أو تحديد سرعة أو تعديل إعدادات الراوتر. هذه الوظائف تحتاج فحص صفحات Access Control وQoS وحقول النماذج أولاً.
- لا يرسل التطبيق بيانات إلى خادم خارجي، ولا يحفظ كلمة مرور الراوتر. أدخل كلمة المرور فقط في صفحة الراوتر المحلية داخل WebView.

## طريقة الاستخدام

1. ثبّت التطبيق واتصل بشبكة الراوتر.
2. افتح `192.168.0.1` من داخل التطبيق وسجّل الدخول في صفحة الراوتر.
3. استخدم اختصار `قائمة أجهزة DHCP` أو افتح `Advanced > DHCP Client List` ثم اضغط `قراءة الأجهزة من الصفحة الحالية`.
4. استخدم اختصار `الأجهزة اللاسلكية المتصلة` أو افتح `Wireless > Wireless Connection Status` ثم اضغط زر القراءة نفسه.
5. ستظهر قائمة موحدة حسب MAC مع بيان ما إذا كان الجهاز موجوداً في كلتا اللقطتين.
6. اضغط Refresh داخل صفحة الراوتر قبل تحديث أي لقطة.

## بناء APK عبر GitHub Actions

1. ارفع محتويات مجلد المشروع إلى مستودع GitHub بحيث يكون `settings.gradle` في جذر المستودع.
2. افتح Actions وشغّل `Build Tenda W303 Guard APK` أو ادفع commit جديداً.
3. نزّل `TendaW303Guard-debug-apk` من Artifacts.

بيئة البناء: JDK 17، Gradle 8.7، Android Gradle Plugin 8.6.1، Android SDK 35.
