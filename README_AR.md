# Tenda W303 Guard — الإصدار 0.2.4

تطبيق Android بلغة Java لإدارة ومراقبة أجهزة راوتر Tenda W303R V3.0، Firmware `V5.07.46_en`.

## الجديد في 0.2.4

- إصلاح فشل الانتقال التلقائي من DHCP إلى صفحة Wireless Connection Status.
- استخدام المسار المؤكد `/wireless_state.asp` وتوجيه إطار المحتوى الموجود بدلاً من الاعتماد على مطابقة اسم رابط القائمة.
- استخدام فتح المسار المحلي المباشر كخطة بديلة مع الحفاظ على جلسة WebView.
- إبقاء عملية الفحص للقراءة فقط؛ لا تُرسل أوامر تغيير إعدادات الراوتر.

## الميزات الموجودة من 0.2.3

- لوحة مشتركين بدلاً من عرض تقرير نصي طويل فقط.
- بطاقات منفصلة لكل جهاز مع الاسم وIP وMAC ومؤشرات DHCP وWi-Fi.
- البحث بالاسم أو IP أو MAC.
- تصفية القائمة إلى الكل أو الأجهزة الظاهرة في Wi-Fi أو سجلات DHCP غير الظاهرة في Wi-Fi.
- نافذة تفاصيل مستقلة لكل جهاز.
- زر لتحديث DHCP ثم Wireless بالتتابع؛ يستخدم الإصدار 0.2.4 مسار Wireless المؤكد مباشرةً بدلاً من النقر على نص القائمة.
- استمرار استخدام أسماء الأجهزة المحلية المحفوظة على الهاتف.
- لا يرسل هذا الإصدار أي أوامر لتغيير إعدادات الراوتر.

## اختبار التحديث المتتابع

1. اتصل بشبكة Tenda وافتح التطبيق.
2. سجّل الدخول إلى واجهة الراوتر من WebView.
3. اضغط `تحديث القائمتين تلقائياً`.
4. يفتح التطبيق `DHCP Client List` ويقرأ الجدول، ثم يوجّه إطار المحتوى إلى المسار المؤكد `/wireless_state.asp` ويقرأ جدول Wireless. إذا لم يجد إطار المحتوى، يحاول فتح المسار المحلي مباشرةً في WebView.
5. إذا لم يتعرف على أحد روابط القائمة، افتح الصفحة يدوياً واستخدم `قراءة الأجهزة من الصفحة الحالية`.

## معنى الحالات

- `متصل عبر Wi-Fi`: عنوان MAC ظهر في لقطة صفحة Wireless Connection Status.
- `DHCP فقط`: الجهاز ظهر في سجل DHCP ولم يظهر في آخر لقطة Wi-Fi. لا يعني ذلك أنه غير متصل بالشبكة؛ قد يكون عبر LAN أو لم يظهر في اللقطة.
- `Wi-Fi فقط`: الجهاز ظهر في قائمة Wireless ولم يوجد له سجل مطابق في لقطة DHCP.
- `20M` أو `40M`: عرض قناة Wi-Fi وليس معدل تنزيل أو رفع الإنترنت.

## حدود الإصدار

- لا توجد مراقبة خلفية مستمرة؛ التحديث المتتابع يتم عند الضغط على الزر والتطبيق مفتوح.
- لا يوجد حظر أو تحديد سرعة أو جدولة مطبقة آلياً في هذا الإصدار.
- لا يتم اختبار التحكم الكتابي قبل فحص صفحات Security وQoS ونماذجها.
- يجب اختبار زر التحديث المتتابع على Firmware الفعلي؛ لا نفترض نجاح التنقل الآلي قبل تأكيده من الهاتف.

## بناء APK عبر GitHub Actions

ارفع محتويات المجلد إلى جذر المستودع بحيث يوجد `settings.gradle` في الجذر، ويكون مسار Workflow هو `.github/workflows/android.yaml`. افتح Actions وشغّل `Build Tenda W303 Guard APK`، ثم نزّل Artifact باسم `TendaW303Guard-debug-apk`.

بيئة البناء: JDK 17، Gradle 8.7، Android Gradle Plugin 8.6.1، Android SDK 35.
